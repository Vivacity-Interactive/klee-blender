A nicer way to share Node Groups

Klee-Blender enables simple sharing of Node Groups created in Blender 4.3. Mainly targeting Geometry Nodes.

No Screenshots needed!

Copy using the blender plugin and paste your Node Group directly from Blender into any modern webbrowser without the need of taking and uploading screenshots.

No more recreating nodes you found on a screenshot. Select it and copy & paste it like it was text-based code.

Simple integration

Klee-Blender is written in TypeScript and compiled to JavaScript. All the magic without any additional dependencies. 

                                
<canvas class="kle-blender"> YOUR COPIED BP CODE HERE </canvas>
...
<script src="klee-blender.min.js"></script>

We aim to support

  • Geometry node groups
  • Base nodes
  • Repeat zone
  • Grouped node
  • Simulation zone
  • Gizmo nodes
  • Reroute nodes (knots)
  • Blender to clipboard copy into as UE serialization
  • Clipboard to Blender copy as UE serialization
  • Export Node Group(s)

Share everywhere

Klee-Blender lets you share Node Groups on your own Website like you would share text-based code. Share for example geometry nodes Node Groups in your forum, your tutoring site or your personal Blog.
